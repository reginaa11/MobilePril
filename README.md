# Лабораторная работа №4: Создание списков

## Описание
Изучение возможностей создания прокручиваемых списков в Jetpack Compose.

## Выполненные задания
1. **Affirmations** — прокручиваемый список карточек с изображениями и текстом (`LazyColumn`).
2. **Topics** — сетка из двух столбцов с карточками тем (`LazyVerticalGrid`).

## Технологии
- LazyColumn
- LazyVerticalGrid
- Card, Image, Text
