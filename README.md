# Лабораторная работа №1: Знакомство с Android Studio

## Описание
Изучение основ работы в среде Android Studio и создание первых приложений.

## Выполненные задания
1. **First App** — создание проекта из шаблона Empty Activity, запуск на эмуляторе.
2. **LinearLayout** — освоение линейной компоновки, размещение трёх TextView (ФИО, стих на русском и английском).
3. **Components** — работа с EditText, ImageView и Button.

## Технологии
- Android Studio
- Jetpack Compose
- LinearLayout, TextView, Button, EditText, ImageView
