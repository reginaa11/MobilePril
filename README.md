# Лабораторная работа №2: События в приложении

## Описание
Изучение обработки пользовательских событий и логирования.

## Выполненные задания
1. **ToastHandler** — обработка нажатия кнопки с выводом Toast-уведомления.
2. **Logging** — логирование через `Log` и `Timber`.
3. **Attributes** — изменение атрибутов текста (цвет, размер, фон) через кнопки.

## Технологии
- Kotlin
- Jetpack Compose
- Toast, Log, Timber
- Обработчики событий (OnClickListener)
