# Лабораторная работа №6: Жизненный цикл. Архитектурные компоненты

## Описание
Изучение жизненного цикла приложения, архитектурного паттерна MVVM и ViewModel.

## Выполненные задания
1. **Unscramble** — игра в слова с использованием `ViewModel` и `StateFlow`.
2. **ActivityLifecycle** — логирование методов жизненного цикла Activity.
3. **DessertClicker** — приложение с кликами по десерту и `ViewModel`.
4. **Тесты** — Unit-тесты для `GameViewModel`.

## Технологии
- ViewModel
- StateFlow, MutableStateFlow
- MVVM
- Unit-тесты (JUnit)
