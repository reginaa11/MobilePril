# Лабораторная работа №5: Взаимодействие с UI и состоянием

## Описание
Изучение вариантов взаимодействия пользователя с интерфейсом и сохранения состояния.

## Выполненные задания
1. **TipTime** — калькулятор чаевых с обработкой ввода и пересчётом.
2. **ArtSpaceApp** — галерея картинок с кнопками «Previous» и «Next».

## Технологии
- State, MutableState
- remember, rememberSaveable
- TextField
- Обработка пользовательского ввода
