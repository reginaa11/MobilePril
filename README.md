# Лабораторная работа №7: Навигация. Адаптив под разный формат экрана

## Описание
Изучение навигации в приложениях и адаптации интерфейса под разные размеры экрана.

## Выполненные задания
1. **LunchTray** — приложение для заказа еды с навигацией между экранами.
2. **MyCity** — гид по городу с категориями и навигацией.

## Технологии
- Navigation Compose
- NavHost, NavController
- ViewModel, StateFlow
- Адаптивный дизайн (WindowSizeClass)
