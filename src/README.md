## Описание

Проект содержит решения 10 заданий лабораторной работы №0 по основам языка Kotlin.
Все задания оформлены в виде отдельных файлов и вызываются из единой точки входа `Main.kt`.

## Как запустить

1. Открыть проект в IntelliJ IDEA.
2. Дождаться синхронизации Gradle.
3. Открыть файл `src/main/kotlin/org/example/Main.kt`.
4. Нажать зелёный треугольник ▶ рядом с `fun main()`.
5. Ввести номер задания (1–10) и следовать инструкциям в консоли.
